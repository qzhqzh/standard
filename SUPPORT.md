# Support

- **Bug reports:** use the bug issue form after reproducing on a supported version.
- **Feature proposals:** use the feature form and explain the user outcome.
- **Usage questions:** use GitHub Discussions when enabled.
- **Security vulnerabilities:** follow `SECURITY.md`; never use public channels.
- **Conduct concerns:** follow `CODE_OF_CONDUCT.md`.

Provide the project version, Python version, operating system, exact command, sanitized output, expected result, and a minimal reproduction. Open-source support is best effort and has no guaranteed response time.
