# Roadmap

The roadmap communicates intent, not a delivery guarantee.

## Near term

- Validate the baseline across additional ecosystems and repository types.
- Add profiles for libraries, services, CLIs, research software, and monorepos.
- Produce machine-readable remediation suitable for automated issue creation.

## Later

- Add content-quality checks, OSPS mappings, GitHub setting checks, and safe remediation patches.
- Add SBOM and release-verification examples for container projects.

## Non-goals

The project does not replace legal advice, security review, threat modeling, or human evaluation. Badge count and scanner score are not proof that software is secure.
